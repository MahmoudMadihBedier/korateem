# كورة تيم

تطبيق كورة تيم هو منصة متكاملة للشباب المصري للبحث وحجز والانضمام إلى ملاعب كرة القدم، وإنشاء فرق، والانضمام إلى المباريات، ومشاركة اللحظات الاجتماعية. جميع الميزات باللغة العربية ومصممة خصيصًا للثقافة المصرية.

## الميزات الرئيسية
- البحث عن الملاعب القريبة حسب الموقع
- حجز المواعيد والانضمام للمباريات
- إنشاء فرق (5 ضد 5)
- ملفات شخصية للمستخدمين وأصحاب الملاعب
- إدارة المواعيد والأسعار والتحديثات (صور وفيديو)
- تقييمات ومراجعات
- مشاركة اجتماعية ودعوات
- مصادقة باستخدام البريد الإلكتروني وجوجل

## التقنيات المستخدمة
- Flutter (واجهة المستخدم)
- Firebase (المصادقة، قاعدة البيانات، التخزين)
- دعم RTL للغة العربية
- تطبيق مبادئ OOP و SOLID

## تجربة المستخدم
واجهة سلسة، سهلة الاستخدام، متوافقة مع الثقافة المصرية، تدعم جميع الأجهزة.

## التوثيق
كل جزء من التطبيق موثق بالكامل لضمان سهولة التطوير والصيانة.

## بنية الخدمات
- كل خدمة في ملف منفصل (مصادقة، مستخدم، ملعب، حجز، فريق، صاحب ملعب)
- جميع الميزات متصلة بقاعدة بيانات Firebase
